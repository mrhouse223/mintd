Liquidity that manages itself,
without asking you to trust us.

Agent-managed Uniswap V3 positions on Arc. You deposit, an agent handles rebalancing, and the contract, not the agent, decides everything that carries value.

The problem with an agent that holds your money

A vault holding user funds is custody. Saying otherwise is a line that has to be walked back later. The keeper key lives on a server, so the question is not whether it can be compromised, it is what a compromised key can take.

The obvious answer is to stop the agent sending funds anywhere it likes. That is not enough. Rebalancing means burning liquidity, swapping to correct the ratio, and minting again. Let the agent set that swap's minimum output and it can trade against itself from an unrelated address. Funds never leave to a strange address, the agent only ever calls rebalance, the exit still points at you, and the vault empties anyway.

So the agent proposes timing, and nothing else

It cannot choose a price

Minimum swap output is computed inside the contract from the pool's own time-weighted average price. The agent passes no slippage parameter at all.

It cannot choose a venue

The pool and fee tier are fixed when the vault is created, and checked against the factory so a lookalike cannot be substituted.

It cannot choose a range

Ranges must contain the average price and sit inside a band you set. A one-sided range would let an agent push your whole balance across the spread.

It cannot grind you down

The vault tracks its own value and halts the agent if it falls past your tolerance. Re-arming is deliberately manual, so a slow drain cannot quietly resume.

You can always leave

Withdrawal goes to the address recorded when the vault was created, needs no agent cooperation, and works even when everything else is paused or broken.

You decide how much rope it gets

PAUSEDThe agent can do nothing at all.
PROPOSE_ONLYThe agent suggests, you approve each action. This is the default.
TIMELOCKEDProposals become executable after a review window unless you veto.
AUTONOMOUSThe agent acts immediately, still inside every limit above.

Changeable at any time, in one transaction, without the agent's cooperation.

Where this actually is

Not deployed. Do not send anything anywhere.

The vault contract is written and tested, including an adversarial test where an attacker is handed the agent role, unlimited calls, and a bankroll thirty times the vault's size. Two independent security reviews have been run against it and the findings fixed. It has not been deployed, it has not been audited by a firm, and Arc mainnet is not publicly live yet.

There is no token. There is no sale. If that changes it will be said plainly here rather than hinted at.
