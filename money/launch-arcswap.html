Set the 2,000 USDC start, then launch ARCSWAP

The start price is owner-settable, so moving from 3,000 to 2,000 needs no redeploy. Connect the owner wallet, set the config, then launch. Driven from the wallet because no reachable Arc RPC answers reads.

Setting the start price changes it for every FUTURE launch, not past ones. A token already launched keeps the pool it was created with, and its creator fee share is snapshotted at launch, so nothing retroactively changes for it.
